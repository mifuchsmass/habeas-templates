HABEAS PETITION GENERATOR — WORD TEMPLATE AUTHORING GUIDE

Updated October 13, 2026

Download Word version (.docx)

Purpose of this guide

The Habeas Petition Generator is a browser application that produces an editable habeas petition as a Microsoft Word document for one named petitioner. The immigration attorney enters information about the case in the Attorney Form shown in the browser, and the application inserts that information into a Word template.

The sample petition uses the defined term “Petitioner” and ordinary singular verbs. The application does not automatically insert, choose, or change pronouns. An immigration attorney may edit the finished Word document to use pronouns where appropriate.

For example, a Word template might say:

Petitioner <Petitioner Name> is detained at <Detention Facility>.

Petitioner brings this petition on Petitioner’s own behalf.

The words in angle brackets tell the application where to insert information supplied by the immigration attorney. The rest of the document stays as written unless the template contains a conditional instruction, explained below.

Important: The included petition is a sample for drafting and testing, not an approved pleading. An attorney must review the finished Word document for legal accuracy, completeness, and formatting.

1. Add fields to the Word template

Use one pair of angle brackets to show where information should appear:

<Petitioner Name> <Detention Facility> <Days In Custody>

A field identifies a place in the document where the application inserts the immigration attorney’s answer. For example, <Petitioner Name> is replaced with the name entered in the Attorney Form. If that field appears several times, the same answer is inserted at each location.

When an author adds a new field name to the Word template used by the Attorney Form, the application automatically creates a corresponding data-entry box in the Attorney Form. This also applies when a field is used only in a condition or a footnote. In Drafting Studio, new fields in an uploaded template appear in its testing area; uploading a template in the Drafting Studio does not change the Attorney Form shown to the immigration attorney. See Section 9 below on how to update the Attorney Form.

The Attorney Form already includes common fields such as jurisdiction, detention facility, petition type, respondent, case number, and separate first, middle, last, and suffix boxes for the petitioner’s name. The application uses those name parts to assemble <Petitioner Name>.

Use consistent field names. Capital letters do not matter, and extra spaces immediately inside the brackets are ignored. But the words, punctuation, spaces within the name, hyphens, and underscores identify distinct fields.

< Facility > and <FACILITY> refer to the same field.

<Date of Entry> and <Date-of-Entry> are different fields.

The application generally inserts answers as entered. For listed detention facilities, it inserts the full facility name. See Section 6 for the names used in conditional instructions. Writing a field name in capitals does not automatically capitalize the answer; use the appropriate formatting in Microsoft Word if the finished text should appear in capitals.

If an answer is missing: The application leaves the field name and its angle brackets in the generated Word document and displays a warning in the browser identifying the missing information. It does not add a “MISSING DATA” label or warning to the pleading.

2. Include language only when a fact applies

Some petition language belongs in the document only when a particular fact is true. A conditional instruction tells the application when to keep that language. For example:

{IF <Days In Custody> >= 180}

Petitioner has been detained for at least 180 days.

{END IF}

If the attorney enters 180 days or more, the sentence is included. If the answer is fewer than 180 days, the sentence is omitted. The instruction lines do not appear in a completed, resolved document.

You can also give the application different wording to choose from:

{IF <Days In Custody> >= 180}

Petitioner has been detained for at least 180 days.

{ELSE IF <Days In Custody> >= 90}

Petitioner has been detained for at least 90 days.

{ELSE}

Petitioner has been detained for fewer than 90 days.

{END IF}

The application uses the first alternative that applies. You may use more than one {ELSE IF ...}. The {ELSE} is optional, but every {IF ...} needs a matching {END IF}.

Important: Always put a complete field name inside angle brackets when writing a condition. For example, write <Detention Facility>, not Detention Facility. Without the brackets, the application will not recognize the text as a field.

3. Write conditions in a consistent way

The instruction itself uses curly braces, such as {IF ...}. The field being tested uses angle brackets, such as <Days In Custody>.

To compare an answer with words, put the words inside double quotation marks. To compare a number, write the number without quotation marks:

{IF <Detention Facility> = "Plymouth"}

{IF <Days In Custody> >= 180}

The most common comparisons are “=” (equals), “!=” (does not equal), “>” (greater than), “<” (less than), “>=” (at least), and “<=” (at most). You must include spaces before and after each comparison symbol. Otherwise, the application will not recognize the condition correctly.

When more than one fact must be considered, you may use AND, OR, NOT, and parentheses. For ordinary petitions, favor short, simple instructions. Examples and special rules appear in the reference at the end.

Keep each instruction together. Use Enter to place each instruction and each line of pleading text in its own Word paragraph. Word may automatically wrap a long instruction onto a second display line, but do not press Enter in the middle of a single instruction. Put the opening and closing instructions in their own unnumbered paragraphs when they control a whole numbered pleading paragraph.

4. What happens when information is missing

The application does not guess a missing fact. If a blank field prevents it from deciding which conditional sentence applies, it keeps the entire conditional passage in the generated Word document and displays a warning in the browser.

For example, if <Days In Custody> is blank, the generated document will still show:

{IF <Days In Custody> >= 180}

Petitioner has been detained for at least 180 days.

{ELSE}

Petitioner has been detained for fewer than 180 days.

{END IF}

This makes the unresolved choice visible to the attorney rather than quietly selecting potentially incorrect language. Other fields with known answers will still be filled in within that passage.

Before using the pleading: Review the on-screen warnings in the browser, fill in missing answers or resolve remaining instructions in Word, and inspect the entire document. The application does not add warning paragraphs or comments to the pleading itself.

5. Use ordinary Word formatting

Prepare the template in Microsoft Word using normal paragraphs, headings, numbering, lists, simple tables, and footnotes. The application is designed to retain these features when it inserts answers or removes language that does not apply.

A condition can cover several ordinary paragraphs, but its instructions must not be split between table cells. Footnotes may contain fields and conditions, but each conditional passage must begin and end within the same footnote or within the main document.

Some Word features need special care. Do not put active template fields or conditional instructions in headers, footers, text boxes, hyperlinks, endnotes, nested tables, content controls, field codes, bookmarks or tracked-change text. The application may reject unsupported instructions to avoid damaging the file.

Square brackets are ordinary legal writing, not fields. Examples such as [sic], [T]he, and claim[s] remain unchanged. If you need to show an actual angle-bracket field or conditional instruction in a generated document, consult the reference at the end of this guide.

Check in Microsoft Word. A successful download or a browser preview does not prove the pleading is ready. Open the generated document in Word and check the text, pagination, paragraph numbering, tables, footnotes, and formatting.

6. Select a detention facility or ICE office

Select the jurisdiction where the petitioner is detained.

For Massachusetts, Rhode Island, New Hampshire, and Vermont, select a listed detention facility or choose “Other detention location…” to enter a facility or ICE office not included in the list.

For Connecticut and Maine, “Other detention location…” is selected automatically because no specific facilities are currently listed.

When “Other” is selected, enter the facility or ICE office name and/or location in the additional field. If that field is left blank, the generated document retains <Detention Facility> and displays a missing-information warning in the browser.

Important: If you change jurisdictions, review the detention-location information carefully. Previously entered custom-location text may remain in the form.

Using detention facility names in Word templates

When writing petition text, use the field <Detention Facility> wherever the full name of the detention facility should appear. The application automatically inserts the full facility name.

7. Preview, download, and save your answers

The Attorney Form opens with blank case information while Drafting Studio populates some sample fields. Once the application's included Word template loads, the form shows the standard fields and any additional fields found in that template.

“Render Preview” shows the document in the browser. “Download Word Document” downloads an editable Microsoft Word file. Your browser saves it to your usual download location or asks where to save it. You can download directly without first generating a preview; both actions use the answers currently in the form.

Starting a new Preview immediately clears any previous preview. Starting a Download leaves any existing preview visible. A preview may be blocked by safety checks on certain symbols or links even when downloading the Word document is allowed.

Warnings in the browser identify fields that need answers, conditional language that could not be resolved, or document problems. Read them before relying on the document. A serious template error or document-generation error prevents a usable document from being produced.

“Save Form Data” downloads your answers in a JSON file so you can restore them later using “Load Saved Data.” Loading saved answers does not automatically generate a petition; select Preview or Download afterward. Because the file may contain confidential client information, store and share it securely. Do not edit the file manually.

8. Test a proposed template in Drafting Studio

Drafting Studio is for people who prepare or revise Word templates. You can upload a document template, inspect its fields and conditional instructions, or paste a short sample for inspection. The Studio contains sample case information for testing; the Attorney Form itself starts blank.

1. Upload the proposed Word template in Drafting Studio.

2. Inspect it, and correct any field, syntax, or Word-structure errors reported.

3. Try several different case examples, including facts that should produce different sentences and fields deliberately left blank.

4. Generate a preview or download a Word document.

5. Open the generated document in Microsoft Word. Check every important legal statement, selected alternative, unresolved placeholder, footnote, table, and numbered paragraph.

Testing has limits. Drafting Studio can find some technical problems; passing its checks does not establish that the legal language is correct or that a template is ready to publish. The attorney drafting the template is fully responsible for the legal content.

9. Submit a proposed template update

Uploading a template to Drafting Studio does not change the template used by the Attorney Form. The Attorney Form continues to use the petition template included with the application.

Updating the Attorney Form’s template requires a change to the application files. This change can only be made by a website administrator with access to the development environment.

If you wish to propose an updated template, please contact the website administrator and provide:

1. The proposed Word template.

2. A description of the changes.

3. Confirmation that you tested the updated template in Drafting Studio and found no syntax errors.

Testing in Drafting Studio does not eliminate the need to review the generated document in Microsoft Word for accuracy, completeness, and formatting before submitting a proposed template for publication.

10. Final checklist

Fields that require answers use angle brackets, for example <Petitioner Name>. Ordinary square brackets remain ordinary text.

Each {IF ...} instruction refers to a complete bracketed field name and has a matching {END IF}.

Different test cases produce the expected language; blank answers lead to visible warnings rather than assumptions.

You have opened and inspected representative generated pleadings in Microsoft Word.

A proposed update includes the revised template, a description of changes, and confirmation of Studio testing.

Quick reference: Field and condition rules

This section is for template authors who need to write or troubleshoot more complicated instructions. Most templates can use the simpler examples above.

Place a backslash before the opening bracket or brace when you want the text to appear literally. The backslash is removed.

Additional points to know:

Text comparisons ignore capitalization and extra spaces at the beginning or end of an answer. Numbers used in numeric comparisons must actually be numbers; do not put them in quotation marks.

Field names may not contain angle brackets, curly braces, backslashes, or paragraph breaks. Use the same spelling consistently, including spaces, hyphens, and underscores.

If a condition cannot be decided because a needed answer is missing, the entire conditional passage remains visible in the document.

A condition may contain another condition, but each must have its own {END IF}. Use nested instructions sparingly and test all outcomes.

Some complex tables, footnote boundaries, tracked changes, field codes, bookmarks and other advanced Word controls and structures cannot safely contain automation instructions. If Drafting Studio reports an unsupported structure, revise the template in Word rather than trying to bypass the error.
